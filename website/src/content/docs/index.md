Welcome to the DataMgmt Node documentation. This guide covers everything you need to know to deploy and operate a decentralized data management node.

## Quick Start

Get up and running in under 5 minutes:

```bash
pip install datamgmtnode
datamgmtnode init --network sepolia
datamgmtnode start
```
